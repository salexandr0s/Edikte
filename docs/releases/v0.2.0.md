# Edikte v0.2.0

## Deutsch

Edikte zeigt jetzt auch Immobilienverkäufe und Verpachtungen in Insolvenzverfahren von JustizOnline. Beide Quellen teilen sich Liste, Karte, Filter und Dokumente; in den Einstellungen wählen Sie die Quellen und Bundesländer.

- Insolvenzangebote zeigen das Veröffentlichungsdatum und den Wert aus der Bekanntmachung. Die KI-Analyse berücksichtigt den jeweiligen Quellentyp.
- Vor Datenbankmigrationen erstellt die App eine konsistente Sicherung unter `migration-backups`. Schlägt die Sicherung fehl, bleibt die Datenbank unverändert.
- Veraltete Analysen bleiben sichtbar, fließen aber nicht in aktuelle Flächen, Preise pro m², Risiken oder Filter ein. Eine neue KI-Analyse starten Sie selbst. Gespeicherte Gutachten lassen sich zur lokalen Flächensuche erneut lesen.
- Dialoge und Karten schließen mit einem passenden Tastaturfokus. Gespeicherte Filter für deaktivierte Quellen bieten einen Weg zurück zu den aktiven Quellen.

Downloads: macOS für Apple-Chip oder Intel, jeweils als DMG und ZIP; Windows als 64-Bit-Installer. Die Builds haben kein Entwicklerzertifikat. Die [Installationsanleitung](https://github.com/salexandr0s/Edikte#installation) erklärt den ersten Start. `SHA256SUMS.txt` enthält die Prüfsummen.

## English

Edikte now includes real-estate sales and leases in insolvency proceedings from JustizOnline. Both sources share the list, map, filters and documents; choose sources and Bundesländer in Settings.

- Insolvency offers show the publication date and value from the notice. AI analysis follows the listing's source.
- Before database migrations, the app saves a consistent backup under `migration-backups`. If saving fails, the database stays unchanged.
- Outdated analyses stay visible but do not feed current areas, prices per m², risks or filters. You choose when to start another AI analysis. Saved reports can be read again for local area extraction.
- Closing dialogs and map cards restores useful keyboard focus. Saved filters for disabled sources offer a way back to enabled sources.

Downloads: macOS for Apple silicon or Intel, each as DMG and ZIP; Windows as a 64-bit installer. Builds have no developer certificate. The [installation instructions](https://github.com/salexandr0s/Edikte#installation-1) explain the first launch. `SHA256SUMS.txt` lists checksums.

## Verification

Typecheck, lint, formatting, 752 unit tests and the Electron smoke test passed before release; two opt-in tests were skipped. Browser checks covered German/English, light/dark, keyboard focus and widths of 960–1440 CSS pixels. A live Vienna check with temporary data completed for both sources and downloaded three sample PDFs. No live AI ran, and testing did not open the real user-data folder.

The release workflow checks each packaged Mac app natively and installs/self-checks the Windows installer before publishing its artifacts. See the [feature review](https://github.com/salexandr0s/Edikte/blob/main/docs/insolvency-sales-review.md) for detailed evidence and remaining verification gaps.
